# 💰 Expense Tracker System

A clean, user-friendly desktop application built with Python and Tkinter for tracking daily expenses, managing personal budgets, and generating analytical spending reports.

---

## ✨ Features

- **CRUD Operations:** Easily **Add**, **Update**, and **Delete** expense records with real-time table refreshing.
- **Persistent Storage:** Automatically saves and loads your financial data locally using JSON (`expenses.json`), preventing data loss across sessions.
- **Smart Search & Filtering:** Instantly search through records by keyword, category, date, or title.
- **Financial Reports:** Generate quick monthly summaries (`YYYY-MM`) and view overall total spending on demand.
- **Cross-Platform UI Design:** Features custom vibrant canvas-styled buttons optimized for macOS display rendering, alongside standard form inputs and a scrollable data table (`ttk.Treeview`).

---

## 🛠️ Tech Stack & Libraries
- **Language:** Python 3
- **GUI Framework:** `tkinter` & `ttk` (Standard Python Library)
- **Data Storage:** `json`
- **Date Handling:** `datetime`
